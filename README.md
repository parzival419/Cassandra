# Cassandra

Cassandra is an AI research platform focused on exploring how system architecture, context, memory, and tooling influence the performance of language models.

Rather than treating the LLM as the entire solution, Cassandra investigates how observation, retrieval, planning, memory, and action combine to create capable AI systems.

## Research Areas

- Agentic AI
- Local LLMs
- Retrieval-Augmented Generation (RAG)
- Multi-step planning
- Telemetry and observability
- AI evaluation
